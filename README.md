### Hi, I'm Dor 👋

M.Sc. student in Machine Learning & Big Data (The Open University of Israel) and software engineer. I build AI-native software in Python: agents that use tools, evals that catch hallucinated figures, pipelines that run unattended. One working rule: the model reasons, deterministic tested code computes.

I develop with AI coding agents daily — in the open (the co-author trailers are in the history) — and review, test and ship everything they touch.

#### Projects

- **[airport-investment-agent](https://github.com/DoriAlagem/airport-investment-agent)**: a tool-calling LLM agent that ranks 396 US airports by suppressed demand. Every figure comes from a deterministic scoring engine, and an eval harness traces each number back to a tool result. FastAPI, Gemini, SQLite, DuckDB; 102 tests in CI.
- **[job-scanner](https://github.com/DoriAlagem/job-scanner)**: an LLM pipeline that scrapes six job sources twice daily, scores listings against a CV, and emails a ranked digest. It has screened 11,000+ listings unattended. 62 tests, runs serverless on GitHub Actions.
