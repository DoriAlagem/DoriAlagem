### Hi, I'm Dor

I'm doing an M.Sc. in Machine Learning & Big Data at the Open University of Israel, after a B.Sc. in Computer Science at HIT. Most of what I build these days is in Python, around LLMs: agents that call tools, and pipelines that run on their own.

Two projects I'm actively working on:

- **[airport-investment-agent](https://github.com/DoriAlagem/airport-investment-agent)**: ranks 396 US airports by demand that current flights don't serve, for investors. The model decides which tools to call, but all the numbers come from a regular scoring engine, so it can't make up a figure. Built with FastAPI, Gemini, SQLite and DuckDB.
- **[job-scanner](https://github.com/DoriAlagem/job-scanner)**: started because I was tired of scrolling job boards. It checks six sites twice a day, scores each listing against my CV and emails me the best matches. It's been running on GitHub Actions for six months.

I also contribute to open source when I find an issue I can fix. I've had PRs merged in [Playwright](https://github.com/microsoft/playwright/pull/40374), [Svelte](https://github.com/sveltejs/svelte/pull/18153), [Vitest](https://github.com/vitest-dev/vitest/pull/10187), [Astro](https://github.com/withastro/astro/pull/16572), [tRPC](https://github.com/trpc/trpc/pull/7336), [TanStack Query](https://github.com/TanStack/query/pull/10610) and a few others.
